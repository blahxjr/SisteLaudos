# Visão: Evolução assistida por Agentes de IA

Fase atual: Estruturação da base para desenvolvimento com agentes de IA.

Idioma principal do projeto: Português do Brasil (pt-BR).

Objetivo desta fase:
- Criar estruturas documentais, ADRs, templates e um módulo de memória persistente para permitir que agentes realizem descoberta e trabalho localizado com segurança.

Próximos passos recomendados:
- Executar a Fase 0 (descoberta completa do repositório).
- Providenciar infra de banco (Postgres) e indexador vetorial quando possível.
- Formalizar políticas de autonomia e handoff usando os templates em `/docs/templates`.
